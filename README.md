# Harell Homebrew tap

Homebrew formula for [`harell`](https://harelldata.com), the command-line
client for the Harell Data platform.

```sh
brew install harelldata/tap/harell
harell version
harell login
```

Upgrade and remove:

```sh
brew update && brew upgrade harell
brew uninstall harell
brew untap harelldata/tap
```

Uninstalling leaves your Harell configuration and session in place. To remove
them too, run `harell logout` before uninstalling, then delete the
configuration directory: `~/Library/Application Support/harell` on macOS,
`~/.config/harell` on Linux (or `$XDG_CONFIG_HOME/harell`). Also delete
`~/.config/harell` if it exists: older releases stored configuration and
sessions there, and Harell still reads it as a fallback.

Supported: macOS (Apple silicon and Intel) and Linux (x86_64 and arm64).

## Direct download

Every release on this repository's
[Releases page](https://github.com/harelldata/homebrew-tap/releases) carries
archives for macOS, Linux, and Windows plus a `checksums.txt`. This is the
path for Windows and for machines without Homebrew:

```sh
shasum -a 256 -c --ignore-missing checksums.txt   # sha256sum on Linux
tar xzf harell_<version>_<os>_<arch>.tar.gz       # unzip the .zip on Windows
```

Put the extracted `harell` (or `harell.exe`) on your `PATH`. The "Source
code" archives GitHub attaches to each release contain only this tap.

## Reporting install problems

Open an issue on this repository with the output of `brew config`,
`brew doctor`, and the failing command, or contact support@harelldata.com.

## How this tap is maintained

`Formula/harell.rb` is generated by the Harell CLI release workflow. For each
stable release, `harell-release-bot` pushes it to a `harell-<version>` branch
and opens a pull request; the `Check formula` workflow verifies it against the
release's `checksums.txt` and installs and tests it on macOS (Apple silicon
and Intel) and Linux (x86_64 and arm64); a code owner approves and a
maintainer merges. `main` accepts no direct pushes, and every change needs a
code owner's approval. Please do not edit the formula by hand; propose a pull
request and the same checks run.
